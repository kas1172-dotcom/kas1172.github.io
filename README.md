# Kapil Sharma — Portfolio

Professional portfolio covering product development, healthcare operations, regulatory analysis, and quantitative work.

[View portfolio](https://kas1172-dotcom.github.io/kas1172.github.io/)

## Structure

- `index.html`: responsive portfolio and project case studies.
- `analyses/`: completed public-data analysis.
- `screenshots/empath/operations.png`: public EMPATH demonstration with synthetic unit totals.
- `Kapil_Sharma_Resume_November2026.docx`: the resume supplied by the author, preserved unchanged.
- `KapilSharma_Resume_.pdf`: PDF rendered from that same supplied DOCX.

The EMPATH demo uses fictional staff labels and synthetic aggregate data. Screenshots do not show patient records or actual hospital results. Private client product implementations are described without publishing their source or internal data.

## Preview

Serve this directory with any static HTTP server, such as `python -m http.server 8000`, and open `http://localhost:8000`. There is no build step. Check section links, project links, both resume downloads, and layout at narrow and desktop widths before publishing.
